# Berry Sweet Tip Calculator 🍓

Name:Helaena Michel M. Razon
Subject: Mobile app development (flutter)
Laboratory Exercise: 01b -  tip calculator

A cute pink and red Flutter tip calculator that calculates tips and totals based on the bill amount and selected tip percentage.

## Features

- Enter a bill amount
- Select 10%, 15%, or 20% tip
- Automatically calculate tip and total
- Validate invalid bill input
- Display amounts with two decimal places
- Cute pink and red Material 3 design
